## 视觉规则

1. **直角**：所有控件 `border-radius: 0`。
2. **点阵底**：页面背景用极淡径向点阵（4px 间距），模拟老 LCD；不用位图资源。linuxfb 上若 QSS 渐变点阵不可靠，退化为纯色底 + 状态条内用 `█░` 字符条。
3. **双线框**：状态条与详情数据区 `border: 4px double #8B9BB4`（或等宽字符框兜底）。
4. **卡片**：白/米边 `3px solid #F4F0E6`，标题前 `▌` + 模块色；摘要次要色。
5. **按钮**：双线或实线粗边；按下反色/内凹；`NoFocus` + 全局 `NoFocusStyle`（已有）。
6. **字体**：微米黑；数据区优先等宽（`monospace`）。

## 页面结构

### 主页

```
┌─ 双线状态条 ─────────────────────┐
│ ▓ ALIENTEK    [OK]    HH:MM:SS   │
│ ██████████████████░░░░░░         │
└──────────────────────────────────┘
┌ 光感 ┐ ┌ 六轴 ┐
┌ 系统 ┐ ┌ 灯控 ┐
┌ 按键 ┐ ┌ OTA  ┐
```

- 模块色：光感青、六轴绿、系统黄、灯控橙、按键青、OTA 绿。
- 摘要每 1s 刷新；时钟每 1s 更新。

### 详情页（光感 / 六轴 / 系统 / OTA / 按键）

- 顶：彩色标题 `■ 模块名`
- 中：双线数据框（等宽、点线对齐数值）
- 底：`[ 返回 ]`

### 灯控页

- 上：双线状态框（LED trigger/brightness、蜂鸣器）
- 中：五个动作按钮（开/关/呼吸灯/蜂鸣开/关）
- 底：返回
