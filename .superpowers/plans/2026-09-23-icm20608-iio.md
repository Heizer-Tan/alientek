# ICM20608 IIO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ICM20608 misc `/dev/icm20608` ASCII ABI with IIO sysfs; migrate read/logger/dashboard in one image cut.

**Architecture:** Out-of-tree SPI driver registers `iio_dev` (accel/anglvel/temp, poll `read_raw` only). Userspace finds device by `name`, reads `*_raw` + `*_scale`/`*_offset`, converts to engineering units. No misc node, no kernel text formatting.

**Tech Stack:** Linux IIO, SPI, out-of-tree module, C userspace helpers, existing SQLite logger / Qt dashboard

**Spec:** `.superpowers/specs/2026-09-23-icm20608-iio-design.md`

## Global Constraints

- Phase 1: ICM20608 only; AP3216C stays misc (documented for phase 2).
- Hard cut: remove `/dev/icm20608`; no dual ABI / no adapter daemon.
- Kernel: IIO sysfs poll only — no buffer/trigger/DRDY.
- No `libiio` dependency in phase 1.
- Chinese comments; keep functions small; do not commit unless user asks.
- Scale/offset must match current hw_init: accel ±2g, gyro ±2000 dps, temp = raw/326.8 + 25.

### Task 1: 内核启用 IIO + 驱动改为 IIO sysfs

**Files:**

- Modify: `meta-alientek/recipes-kernel/icm20608/files/Makefile`

**Interfaces:**
- Produces: IIO device `name=icm20608` with channels listed below; **no** `/dev/icm20608`

**IIO channels / scale (fixed hw_init):**

| Channel | raw | scale (read) | offset |
|---------|-----|--------------|--------|
| `in_accel_*` | s16 | `IIO_VAL_FRACTIONAL` 1/16384（单位 g） | 0 |
| `in_anglvel_*` | s16 | `IIO_VAL_FRACTIONAL` 2000/32768（dps）或等价 INT_PLUS_MICRO | 0 |
| `in_temp` | s16 | 与 `temp_c = raw/326.8 + 25` 一致：scale=1000/326800（或 FRACTIONAL 10/3268），offset=`+25` 经 IIO offset 约定 | 见实现注 |

温度实现注：IIO 惯例 `processed = raw * scale + offset`。选：
- `scale` = `IIO_VAL_FRACTIONAL` val=10, val2=3268（即 10/3268）
- `offset` = `IIO_VAL_INT` 25 / scale？更稳妥：`offset` 用 `IIO_VAL_INT` 表示 **processed offset in same unit as raw\*scale**。常用写法：`offset` = 25 / scale 的 raw 等价，或 scale 用 micro、offset 用整数 °C。实现时以 `iio_convert_raw_to_processed` 语义为准，并对旧公式做对照断言（Task 2 单测）。

- [ ] **Step 3: 重写 icm20608.c 骨架**

保留：寄存器宏、`hw_init`（WHO_AM_I、复位、PWR、SMPLRT、CONFIG、GYRO/ACCEL 量程）、SPI MODE0。

删除：misc、`format_line`、所有 `scnprintf_*`、`file_operations`。

新增要点：

```c
#include <linux/iio/iio.h>
#include <linux/iio/sysfs.h>

struct icm20608_state {
	struct spi_device *spi;
	struct mutex lock;
	/* 可选：最近一次 14 字节缓存，同一次 read_raw 多通道共享 */
};

static const struct iio_chan_spec icm20608_channels[] = {
	/* IIO_ACCEL modified X/Y/Z, info_mask_separate RAW,
	   info_mask_shared_by_type SCALE */
	/* IIO_ANGL_VEL 同上 */
	/* IIO_TEMP，RAW + SCALE + OFFSET */
};

static int icm20608_read_raw(struct iio_dev *indio_dev,
			     struct iio_chan_spec const *chan,
			     int *val, int *val2, long mask);
```

`read_raw`：
- `IIO_CHAN_INFO_RAW`：mutex 下 burst 读 `0x3B` 起 14 字节，按通道取 be16。
- `IIO_CHAN_INFO_SCALE` / `OFFSET`：返回上表常数。

probe：`devm_iio_device_alloc` → `hw_init` → `iio_device_register`。  
remove：`iio_device_unregister`（若非 devm）+ sleep `PWR_MGMT_1=0x40`。

SPI 读寄存器改为 `spi_write_then_read`（cmd 一字节 `reg|0x80`，再读 len）。

### Task 2: 用户态 IIO 读数辅助 + 换算单测

**Files:**
- Create: `meta-alientek/recipes-apps/common/iio-icm.h`
- Create: `meta-alientek/recipes-apps/common/iio-icm.c`
- Create: `tests/test_iio_icm_convert.sh`
- （各 app recipe 通过 `file://` 拷贝 common，或 FILESEXTRAPATHS；与现 `sensor-dashboard` 用 common 方式对齐）

**Interfaces:**
- Produces:

```c
struct IcmSample {
	int ax, ay, az, gx, gy, gz, temp_raw;
	double ax_g, ay_g, az_g, gx_dps, gy_dps, gz_dps, temp_c;
	int valid; /* 或 bool */
};

/* 按 name 查找 iio:device*；找到返回 sysfs 目录路径，调用方 free；未找到 NULL */
char *iioIcmFindSysfsDir(const char *name);

/* 从 sysfs 目录读 raw+scale+offset 填满 sample；成功 0 */
int iioIcmReadSample(const char *sysfsDir, struct IcmSample *out);

/* 仅换算（单测）：raw + scale/offset → 工程量 */
void iioIcmConvert(struct IcmSample *s, double accel_scale, double gyro_scale,
		   double temp_scale, double temp_offset);
```

- [ ] **Step 1: 写宿主换算单测（可无 sysfs）**

`tests/test_iio_icm_convert.sh`：编译只含 `iioIcmConvert` 的测试，断言：
- accel raw=16384 → ≈ 1.0 g（scale=1/16384）
- gyro：对照旧 `raw*10/164` 与新 `raw*2000/32768` 在典型值上误差可接受（或统一采用数据手册 2000/32768，并更新 README 说明）
- temp：raw=0 → ≈ 25.0°C

旧驱动陀螺用 16.4 LSB/dps（即 /16.4），手册 ±2000dps 为 16.4 LSB/(°/s)，即 scale=1/16.4=10/164。IIO 用 FRACTIONAL `10/164` 或 `2000/32768`（32768/2000=16.384）——**一期统一用 10/164 与旧演示一致**，避免读数跳变。

- [ ] **Step 2: 实现 iio-icm.c**

- `iioIcmFindSysfsDir("icm20608")`：扫 `/sys/bus/iio/devices/`
- 读文件辅助：`read_sysfs_s64` / `read_sysfs_scale`（处理 `1.000000` 或 `0.000061` 文本）
- 一次读取填 `IcmSample`，`valid=1`
